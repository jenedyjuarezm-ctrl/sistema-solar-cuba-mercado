# Evidencias del Trabajo de Campo

Esta carpeta contiene el respaldo fotográfico y documental de la investigación primaria realizada para este proyecto de ciencia de datos.

## Política de Privacidad y Ética de Investigación

Para garantizar la seguridad y el anonimato de las personas que colaboraron en este estudio, se establecieron las siguientes reglas:

1. **Firmas de Consentimiento Informado (`firmas_consentimiento/`):**
   *   Se recolectaron las firmas físicas de todos los participantes (residentes y encargados de centros) como prueba de consentimiento.
   *   **Estas firmas NO se suben a GitHub.** Permanecen bajo resguardo del investigador en formato físico y digital local.
   *   La carpeta solo contiene un archivo `.gitkeep` para mantener la estructura del repositorio, pero las imágenes están excluidas por protección de datos personales.

2. **Fotos de Etiquetas de Equipos (`etiquetas_equipos/`):**
   *   Se suben a GitHub únicamente fotografías de las etiquetas de inversores, baterías y estaciones de energía.
   *   **Ninguna foto expone a las personas ni sus rostros.**
   *   Estas imágenes sirven como **evidencia de validación técnica**, permitiendo comprobar que los datos reportados en las encuestas (ej. capacidad en kWh de una batería) coinciden con la realidad física del equipo instalado.

*Nota para el evaluador:* La existencia de este registro fotográfico técnico, junto con las firmas físicas en poder del autor, demuestra la veracidad de los datos estructurados en la carpeta `data/raw/`.
