# Inventario de Evidencias Técnicas (Etiquetas de Equipos)

Este documento registra el inventario de las fotografías tomadas a las etiquetas de los equipos (inversores, baterías y estaciones portátiles) durante el trabajo de campo. 

**Objetivo Metodológico:** Validar empíricamente los datos auto-reportados por los usuarios en las encuestas. En muchos casos, los usuarios desconocen la capacidad técnica exacta de sus equipos, por lo que la foto de la etiqueta se convierte en la fuente de verdad para el análisis.

### Notas Adicionales para el Evaluador
1. **Fotos de Firmas:** Las firmas de consentimiento informado de estos residentes se encuentran resguardadas en la carpeta local `firmas_consentimiento/` (no expuestas por privacidad).
2. **Equipos no fotografiados:** No todos los residentes permitieron el acceso a sus equipos por desconfianza o falta de tiempo. Los datos de esos residentes (sin foto) se mantienen en la base de datos confiando en el auto-reporte, pero se marcan como "No verificados visualmente" en el análisis de sensibilidad.
