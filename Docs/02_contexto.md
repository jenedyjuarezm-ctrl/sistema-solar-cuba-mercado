# Contexto

## Situación energética en Cuba

Según el Anuario Estadístico de Cuba 2024 (ONEI):

- Alta dependencia de importaciones de petróleo.
- Matriz energética dominada por combustibles fósiles.
- Generación total cayó de 19,070 GW·h (2020) a 14,344 GW·h (2024).
- Pérdidas eléctricas: 16–18% del total generado.

## Rol de las energías renovables

- Hidroeléctricas: 91–120 GW·h/año.
- Eólica + Fotovoltaica: 214–265 GW·h/año.
- Potencia instalada PV+Eólica: 221–273 MW.

## Limitaciones de datos

- El cuadro 10.18 no distingue eólica de fotovoltaica.
- No incluye sistemas residenciales privados.
- Rezago de 1 año en publicación.

## Relevancia

Las solineras comunitarias y los sistemas distribuidos son clave para
reducir pérdidas y aumentar resiliencia. Este proyecto genera evidencia
para priorizar inversiones y mantenimiento.
