## Metodologia de proyecto
 
 # Enfoque general 
 Investigacion **mixta** (cuantitativa + caulitativa) con 
 alcance descriptivo - exploratorio

 ## Diseño metodológico
 Fase 1 Revision documental´
 - Búsqueda de fuentes oficiales
 - Sistematización en fichas

Fase 2 Captura de datos
- Descarga de datasets públicos 
- Entrevistas estructuradas 
- Observación con permisos

Fase 3 Estructuración 
- Limpieza de datos 
- Normalización de formatos (CSV,JSON)
- Validación de calidad 

Fase 4 Analísis 
- Estadística descriptiva
- Analísis temporal 
- Métodos estadísticos 
- Visualización 

Fase 5 Documentación 
- Journal dirario 
- Handoff entre sesiones 
- Informe final 
- Repositorio GitHub

Métodos cuantitativos 
 Método     -------     Uso 
----------           ----------
Media,mediana,moda     Tendencias centrales 
Desviación estándar    Dispersión de datos 
Series temporales      Evolución anual 
Correlación            Rleación entre variables 

Métodos cualitativos
Método     -------     Uso 
----------           ----------
Entrevistas        Formularios diseñados 
estructuradas        para técnicos y personal 
Analísis temáticos   Patrones en respuestas 
Traingulación        Validar hallazgos 

Herramientas
Python : pamdas, matplotlib,seaborn
Jupyter : analísis interactivo 
Git/GitHub :  control de versiones 
OpenCode: Asistencia con IA
CSV : datos tabulares

Consideraciones éticas
- Consentimiento informado 
- Anonimato de participantes 
- Cita rigurosa de fuentes 
- Transparencia metodológica 
- Verificación de resultados 

Limitaciones previstas 
- Acceso limitado a datos oficiales 
- Posible desactualización de cifras
- Recursos computacionales limitados
- Tiempo acotado por el semestre
